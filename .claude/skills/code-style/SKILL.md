## Try to use the semantic HTML tags as much as possible. For example, use `<header>`, `<footer>`, `<main>`, `<section>`, `<article>`, etc., instead of generic `<div>` tags as much as possible where it makes sense so that the HTML structure is more meaningful and accessible as well as SEO friendly. I want to harness the full potential power of semantic HTML to improve the overall quality and accessibility of the web pages.

## Use lucide icons for all the icons in the project.

## Creating the any new react component

```
export default function ComponentName() {
  return (
    <div>
      {/* Your component code here */}
    </div>
  );
}
```

## Creating the any new react component with props

```
export default function ComponentName({ prop1, prop2 }: { prop1: string; prop2: number }) {
  return (
    <div>
      {/* Your component code here */}
    </div>
  );
}
```
